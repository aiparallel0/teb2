PART A — BACKEND FIXES (aiparallel0/teb2)
══════════════════════════════════════════

── A1. OAuth cfg=NULL segfault ─────────────────────────────
Problem: agents/oauth.c calls oauth_exchange(..., NULL, msg.db, ...)
passing NULL for Config*. exec/oauth_http.c dereferences cfg for
client credentials → segfault at runtime.

Fix: Add Config *cfg to AgentMsg in core/types.h:
  typedef struct {
      MsgTag tag; int64_t id; char user_id[64];
      char payload[512]; Err err; Db *db; Config *cfg;
  } AgentMsg;

Update agents/coord.c and every site that constructs an AgentMsg
(api/workflow.c, api/oauth.c, api/sse.c) to set .cfg = ctx->cfg.

In agents/oauth.c handle_exchange() and handle_refresh(), replace
the NULL argument with msg.cfg.

── A2. Asset upload body cap ───────────────────────────────
Problem: HttpReq.body is char body[4096]. Uploads > 4096 bytes are
silently truncated before handle_asset_upload sees them. No error.

Fix: In api/assets.c handle_asset_upload(), before writing to disk,
check req.body_len >= sizeof(req.body) - 1. If so, return
json_error(413, "payload_too_large"). This makes the limit explicit
and safe rather than a silent truncation. Document in api/api.h
comment that body max is 4095 bytes.

── A3. SSE body JSON-escape ────────────────────────────────
Problem: In api/sse.c, chat message body is written raw into
sse_write() data field. A body containing " or \n or \ breaks
the SSE event stream framing.

Fix: In the polling loop in handle_sse_subscribe(), escape the body
before snprintf using the existing json_escape() from api/escape.h:
  char eb[512];
  json_escape(cr.rows[i].body, eb, sizeof(eb));
  snprintf(buf, sizeof(buf),
           "{\"id\":%lld,\"body\":\"%s\"}",
           (long long)cr.rows[i].id, eb);

Add #include "api/escape.h" to api/sse.c.

── A4. Metrics bucket overflow indicator ───────────────────
Problem: api/metrics.c silently drops route metrics after 16 unique
(method, path, status) combinations.

Fix: Add a static long mb_overflow counter. Increment it when
mb_count == METRIC_SLOTS and no match found. In handle_metrics(),
append one final line to the output:
  teb_routes_dropped_total %ld\n
using mb_overflow. Declare mb_overflow as static long mb_overflow = 0
